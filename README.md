# Priya Areti — Interactive Analytics Portfolio

Live site: https://priyaareti14.github.io/

Personal portfolio featuring business analytics, market strategy, product analytics and forecasting projects.

## Site structure
This GitHub Pages repository uses a **flat layout**: all HTML files and images are in the repository root. This is intentional because the original folder structure was flattened during the initial GitHub browser upload.

- `index.html`: homepage
- `mobility.html`, `ecommerce.html`, `wti.html`: case studies
- `styles.css`, `script.js`, `config.js`: design, interactions and optional Power BI public URL
- `priya-portrait.jpg`: About photo
- `01_overview.webp` through `06_methodology.webp`: Power BI screenshots
- `favicon.svg`: website icon

## Interactive Power BI
If a public Publish to web link becomes available, set `powerBiPublicUrl` in `config.js`. The Autonomous Mobility case study will reveal a live interactive report in addition to its static screenshots. Public Power BI embedding is subject to Power BI permissions and public-data safety checks.
